# Services Overview

OpenStair Technologies provides software development services across mobile, web, backend, and full stack product delivery.

The services collection is the canonical source for what OpenStair can build and how each service area should be described.

## Core Service Areas

- Flutter development
- Web development
- Backend development
- API integration
- Full stack delivery

## Delivery Approach

OpenStair starts by clarifying the business goal, product context, users, technical constraints, and launch expectations.

The implementation approach should match the product stage. A small MVP should not carry unnecessary platform complexity. A production system should have stronger architecture, security, maintainability, and operational readiness.

## Use Of This Collection

Service documents should describe capabilities, scope, delivery concerns, and engineering considerations. They should avoid repeating the company mission, vision, or values.
