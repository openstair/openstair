# OpenStair Knowledge Platform

The OpenStair Knowledge Platform is the source of truth for durable company knowledge.

Phase 1 establishes the foundation: a safe content source, a small document model, static rendering, and clear boundaries between content, application logic, and presentation.

## What belongs here

- Company documentation
- Engineering standards
- Product documentation
- Architecture decisions
- Future public and internal knowledge

## Phase 1 boundaries

This initial version intentionally stays small. It supports Markdown Document Format v1, public documents, and direct URL access at `/docs`.
