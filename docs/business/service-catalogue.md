# Service Catalogue

## Introduction

OpenStair Technologies provides software development services for organizations that need mobile applications, web applications, backend systems, integrations, or full stack product delivery.

This service catalogue is a composed business asset. It summarizes OpenStair's current service capabilities for prospective clients, enterprise procurement, proposals, partnerships, vendor registration, and future website reuse.

Canonical service descriptions are maintained in the services collection.

## Service Philosophy

OpenStair services are organized around practical delivery and maintainable implementation.

The company starts with the business goal, target users, required platforms, technical constraints, timeline, and operational expectations. The implementation approach should match the product stage and expected lifetime.

OpenStair can support one software layer, such as a mobile app or backend API, or combine multiple layers into a complete product delivery.

## Core Services

## Flutter Development

### Overview

OpenStair builds Flutter applications for businesses that need cross-platform mobile products with maintainable code and polished user experience.

Flutter is suitable when a product needs to reach Android and iOS users from a shared codebase while preserving interface quality and iteration speed.

### Typical Solutions Delivered

- Customer-facing mobile applications
- Internal mobile tools
- MVP mobile apps
- Mobile apps connected to backend APIs
- Apps with authentication, local storage, notifications, analytics, or payment integrations

### Technology Stack

- Flutter
- Dart
- Android platform tooling
- REST APIs
- Firebase where appropriate
- Third-party SDK integrations

### Typical Clients

- Startups building initial mobile products
- Businesses modernizing customer or operational workflows
- Product teams needing cross-platform mobile development
- Service businesses requiring mobile access for customers or staff

### Business Value

Flutter development can reduce duplicated platform work, support faster iteration, and provide a practical path from MVP to production mobile product.

## Web Development

### Overview

OpenStair builds responsive websites and web applications for businesses that need clear presentation, reliable user experience, and maintainable frontend foundations.

Web development may include company websites, product websites, dashboards, internal tools, and web platforms connected to backend systems.

### Typical Solutions Delivered

- Responsive business websites
- Product websites
- Web applications
- Admin dashboards
- Internal business tools
- Frontend interfaces connected to backend APIs

### Technology Stack

- Next.js
- React
- TypeScript
- Semantic HTML
- REST API integration
- Vercel where appropriate

### Typical Clients

- Businesses needing a professional web presence
- Product teams building browser-based interfaces
- Organizations requiring internal dashboards or operational tools
- Companies needing SEO-aware public pages

### Business Value

Web development can help organizations present services clearly, support customer workflows, improve operational visibility, and provide browser-based access to software systems.

## Backend Development

### Overview

OpenStair builds backend systems that support mobile apps, web applications, dashboards, and business workflows.

Backend development includes APIs, data models, authentication, integrations, and operational foundations required beyond the user interface.

### Typical Solutions Delivered

- REST APIs
- Authentication and authorization systems
- Database-backed applications
- Business logic services
- Third-party integrations
- Admin and operational workflows
- Backend support for mobile and web products

### Technology Stack

- Spring Boot
- REST APIs
- PostgreSQL
- Firebase where appropriate
- Authentication systems
- Third-party service integrations

### Typical Clients

- Mobile or web product teams needing secure APIs
- Businesses requiring database-backed systems
- Organizations connecting multiple services or platforms
- Teams needing backend foundations for new or existing products

### Business Value

Backend development provides the secure and reliable foundation needed for product functionality, data ownership, integrations, and long-term system growth.

## Engineering Practices

OpenStair treats engineering as a responsibility to create software that can be understood, operated, maintained, and improved.

The company prefers architecture that matches the product stage and risk. Important decisions should be understandable, and significant architectural choices should be documented when they affect future work.

Engineering practices are guided by maintainability, clear boundaries, explicit ownership, diagnosable failures, security awareness, performance, accessibility, and user experience.

OpenStair works across the main layers required by modern software products: mobile applications, web interfaces, backend systems, databases, integrations, and deployment foundations.

Technology selection should be based on project requirements, maintainability, platform needs, team capability, and expected system lifetime.
