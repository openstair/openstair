# Core Values

OpenStair Technologies uses these values to guide company decisions, client relationships, documentation, and daily work.

## Clarity

Important work should be understandable. Requirements, responsibilities, assumptions, decisions, and risks should be communicated clearly.

## Reliability

OpenStair should deliver work that clients can depend on. Reliability applies to software behavior, communication, documentation, and follow-through.

## Practicality

Solutions should fit the real need. The company should avoid unnecessary complexity while still protecting future maintainability.

## Ownership

Important work should have a responsible owner. Ownership includes decisions, systems, documents, processes, and client commitments.

## Trust

Trust is earned through honest communication, careful handling of information, realistic commitments, and consistent delivery.

## Continuous Improvement

The company should improve its processes, documentation, technical standards, and delivery practices as it learns from real projects.
