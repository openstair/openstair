# Technology Expertise

OpenStair Technologies works across the main layers required by modern software products: mobile applications, web interfaces, backend systems, databases, integrations, and deployment foundations.

Technology choices should be based on the product goal, maintainability, team capability, platform requirements, and expected lifetime of the system.

## Core Technologies

- Flutter
- Dart
- Android
- Kotlin
- Next.js
- React
- TypeScript
- Spring Boot
- REST APIs
- PostgreSQL
- Firebase
- Vercel

## Capability Areas

- Cross-platform mobile app development
- Native Android development
- Responsive web development
- Backend API development
- Authentication and authorization
- Database-backed application design
- Third-party integrations
- Documentation and knowledge platform development

## Technology Position

OpenStair is not defined by a single framework. Frameworks are tools for building useful systems.

The company should choose technology that supports the product's business goal, user experience, security needs, maintainability, and deployment context.
